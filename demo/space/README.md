# ControlSpec interactive examples

Explore seven personal-spending and sales scenarios generated by the real
ControlSpec reference evaluator. This free static Space displays recorded outputs;
it does not run a live evaluator, authorize actions, or execute tools.

[Source and quickstart](https://github.com/claytonsamples/controlspec) ·
[Experimental release](https://github.com/claytonsamples/controlspec/releases/tag/v0.1.1-preview.1)

Select a scenario, inspect its route and outcome assessment, and try the recorded
changed-intent check for the $42 purchase. Raw observations are downloadable.
Reproduce the data with `scripts/build_static_demo.py` in the source repository.
All examples use explicit fixed reference time. No signup or keys are needed.

This browser replays recorded results; it does not evaluate new policies or run an LLM. The local Python harness runs the real reference evaluator and simulates target changes. A sandbox event proves only that simulation occurred. Production identity, credential isolation, enforcement, and durable evidence remain separate work. The baseline isolates ControlSpec’s contribution; it is not a claim that other agent systems lack safeguards.
